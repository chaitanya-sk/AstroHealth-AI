# AstroHealth AI — Datasets

This directory holds local health datasets, simulated telemetry records, and benchmark data for astronaut monitoring.

## Data Types Supported

- **REAL**: Empirical flight, bed-rest analogue, or validated physiological measurements.
- **SIMULATED**: Synthetic, telemetry-driven, or mission-scenario simulated test vectors.
- **RESEARCH**: Academic or published aerospace bio-medicine study reference data.

> **Crucial Rule**: Simulated test data must never be mixed or merged with real flight telemetry.
